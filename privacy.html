개인정보처리방침

최종 수정일 2026년 11월 25일

이 방침은 YouTube Cloud Chrome 확장 프로그램과 소개 페이지에 적용됩니다. 확장 프로그램은 시청 중인 유튜브 영상의 타임스탬프 댓글을 해당 장면 위에 띄우고 재생바에 댓글 분포를 표시합니다.

처리하는 정보와 사용 목적

  • 시청 중인 영상. 현재 유튜브 영상 주소, 영상 ID와 재생 시점을 사용해 해당 영상의 댓글을 가져오고 표시 시점을 맞춥니다.
  • 공개 댓글. 댓글 본문에서 타임스탬프를 찾고 댓글 ID로 중복을 제거합니다. 작성자 표시 이름은 사용자가 이름 표시를 켰을 때 영상 위에 함께 표시합니다.
  • 표시 설정. 기능 사용 여부, 표시 방식, 위치, 개수, 시간, 지연 시간, 글자 크기, 불투명도, 작성자 이름과 댓글 분포 그래프 설정을 Chrome에 저장해 다음 사용 때 적용합니다.

유튜브 요청과 정보 공유

기본 수집 방식에서는 댓글을 불러오는 HTTPS 요청을 www.youtube.com으로 직접 보냅니다. 요청에는 대상 영상 ID 또는 댓글 페이지 토큰과 유튜브 페이지가 제공한 클라이언트 정보가 포함되며, 방문자 식별자가 제공되면 함께 사용합니다. 브라우저가 기존 유튜브 쿠키를 이 요청에 포함할 수 있습니다.

API 키, 댓글, 작성자 이름, 시청 정보와 설정은 개발자 서버에 전송하지 않으며, 이러한 정보를 판매하거나 광고 및 신용평가 목적으로 사용하지 않습니다. Google 및 YouTube가 처리하는 정보에는 Google 개인정보처리방침이 적용됩니다.

유튜브에서 받은 정보는 댓글 표시, 댓글 분포와 수집 진행률을 제공하는 데 사용합니다. 정보 처리는 Chrome 웹 스토어 사용자 데이터 정책의 제한적 사용 요건을 따릅니다.

YouTube Data API 사용

YouTube Cloud는 고급설정에서 사용자가 선택할 수 있는 댓글 수집 방식으로 YouTube Data API를 사용합니다. API 모드를 켜면 공개 댓글과 답글, 작성자 표시 이름, 영상의 댓글 수를 조회합니다. 이를 위해 입력한 API 키를 HTTPS 요청 헤더에 담아 www.googleapis.com으로 직접 보내며, 조회에 필요한 영상 ID, 상위 댓글 ID 또는 페이지 토큰을 함께 보냅니다. 연결 테스트를 누르면 입력한 키와 테스트용 공개 영상 ID를 Google에 보냅니다.

API 요청에는 유튜브 로그인 쿠키가 포함되지 않으며 Google 계정 로그인이나 OAuth 권한을 요청하지 않습니다. API 기능 이용에는 YouTube 서비스 약관이 적용됩니다.

저장한 API 키와 API 사용 여부는 현재 Chrome 프로필의 확장 프로그램 로컬 저장소에 보관합니다. 쿼터를 표시하기 위해 같은 저장소에 키의 해시값, 이 브라우저에서 보낸 일일 요청 수, 쿼터 소진 여부를 저장합니다. 이 사용량은 미국 태평양 시간 기준으로 날짜가 바뀌면 새로 계산합니다.

보관과 삭제

영상과 댓글 데이터는 재생 탭의 메모리에서 처리하며, 영상이 바뀌거나 탭을 닫으면 기존 데이터가 지워집니다. 방문한 페이지 목록은 저장하지 않습니다. 표시 설정은 Chrome 로컬 저장소에 보관되며 팝업에서 바꿀 수 있습니다. 확장 프로그램을 삭제하면 로컬 설정도 삭제됩니다.

팝업에서 댓글 표시를 끄면 새 댓글 요청과 표시가 중단됩니다.

고급설정에서 YouTube Data API를 끄면 기본 수집으로 돌아가며 저장된 키는 남습니다. 키를 지우려면 API를 끈 뒤 입력란을 비우고 키 저장을 누르세요. 확장 프로그램을 삭제하면 저장된 키와 로컬 쿼터 기록도 삭제됩니다.

소개 페이지

소개 페이지의 미리보기는 예시 댓글을 사용합니다. 소개 페이지에는 방문자 분석 도구가 없으며, 호스팅 서비스인 GitHub Pages는 보안 목적으로 방문자의 IP 주소를 기록합니다. 자세한 사항은 GitHub 개인정보처리방침을 확인해 주세요.

문의와 변경 안내

개인정보 처리에 관한 문의는 프로젝트 문의 페이지에 남길 수 있습니다. 문의 글은 공개되므로 개인정보나 API 키는 적지 말아 주세요. 처리방침이 바뀌면 이 페이지의 내용과 최종 수정일을 갱신합니다.
