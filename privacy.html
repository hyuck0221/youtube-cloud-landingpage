개인정보처리방침

시행일 2026년 11월 23일

이 방침은 YouTube Cloud Chrome 확장 프로그램과 소개 페이지에 적용됩니다. 확장 프로그램은 시청 중인 유튜브 영상의 타임스탬프 댓글을 해당 장면 위에 띄우고 재생바에 댓글 분포를 표시합니다.

처리하는 정보와 사용 목적

  • 시청 중인 영상. 현재 유튜브 영상 주소, 영상 ID와 재생 시점을 사용해 해당 영상의 댓글을 가져오고 표시 시점을 맞춥니다.
  • 공개 댓글. 댓글 본문에서 타임스탬프를 찾고 댓글 ID로 중복을 제거합니다. 작성자 표시 이름은 사용자가 이름 표시를 켰을 때 영상 위에 함께 표시합니다.
  • 표시 설정. 기능 사용 여부, 표시 방식, 위치, 개수, 시간, 지연 시간, 글자 크기, 불투명도, 작성자 이름 표시 설정을 Chrome에 저장해 다음 사용 때 적용합니다.

유튜브 요청과 정보 공유

댓글을 불러오는 HTTPS 요청은 www.youtube.com으로 직접 전송됩니다. 요청에는 대상 영상 ID 또는 댓글 페이지 토큰과 유튜브 페이지가 제공한 클라이언트 정보가 포함되며, 방문자 식별자가 제공되면 함께 사용합니다. 요청은 유튜브와 같은 사이트에서 이루어지므로 브라우저가 기존 유튜브 쿠키를 요청에 포함할 수 있습니다.

확장 프로그램은 가져온 댓글, 작성자 이름, 시청 정보 또는 설정을 개발자 서버에 전송하지 않으며, 이러한 정보를 판매하거나 광고 및 신용평가 목적으로 사용하지 않습니다. 유튜브가 처리하는 데이터에는 Google 개인정보처리방침이 적용됩니다.

유튜브에서 받은 정보는 댓글 표시와 댓글 분포 제공에만 사용하며, Chrome 웹 스토어 사용자 데이터 정책의 제한적 사용 요건을 따릅니다.

보관과 삭제

영상과 댓글 데이터는 재생 탭의 메모리에서 처리하며, 영상이 바뀌거나 탭을 닫으면 기존 데이터가 지워집니다. 방문한 페이지 목록은 저장하지 않습니다. 표시 설정은 Chrome 로컬 저장소에 보관되며 팝업에서 바꿀 수 있습니다. 확장 프로그램을 삭제하면 로컬 설정도 삭제됩니다.

팝업에서 댓글 표시를 끄면 새 댓글 요청과 표시가 중단됩니다.

소개 페이지

소개 페이지의 미리보기는 예시 댓글을 사용합니다. 소개 페이지에는 방문자 분석 도구가 없으며, 호스팅 서비스인 GitHub Pages는 보안 목적으로 방문자의 IP 주소를 기록합니다. 자세한 사항은 GitHub 개인정보처리방침을 확인해 주세요.

문의와 변경 안내

개인정보 처리에 관한 문의는 프로젝트 문의 페이지에 남길 수 있습니다. 문의 글은 공개되므로 개인정보는 적지 말아 주세요. 처리방침이 바뀌면 이 페이지의 내용과 시행일을 갱신합니다.
