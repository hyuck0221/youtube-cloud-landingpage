Chrome에서 시작하기

Chrome 120 이상에서 사용할 수 있어요.

확장 프로그램 다운로드
  1. 다운로드한 ZIP 파일을 압축 해제합니다.
  2. Chrome 주소창에 chrome://extensions를 입력하고 개발자 모드를 켭니다.
  3. 압축해제된 확장 프로그램을 로드합니다를 누르고 압축을 푼 폴더를 선택합니다.
  4. 이미 열려 있는 유튜브 탭은 새로고침합니다.
